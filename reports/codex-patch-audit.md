## Additional driver corrections

0019 directs descriptor-bank allocation cleanup to the array passed by the caller. The same allocator serves WBM and monitor descriptors. Freeing the global WBM array after partial monitor allocation can leave live hardware references and unreleased monitor memory. 0022 releases the preallocated WBM idle ring when link setup fails, and frees earlier TX status FIFOs when a later FIFO fails. The latter loop matters for other supported hardware with several TX rings. Neither correction changes ring geometry or assumes that a real AX23 previously hit these paths.

0023 removes only the two AX23 calls to ath11k_remove_regdomain. Original MAC derivation and checksum handling remain in place. The radio-specific hotplug regression checks both ART offsets and that neither branch clears the factory regulatory words. If firmware rejects a factory setting, capture the rejection before any RF change.

## OEM comparison and practical limits

VERIFIED BY OEM SOURCE ANALYSIS. The signed EU 1.2.1 Build 20261026 mp02.1 DT contains GPIO 26 under MDIO and GPIO 39 in the QCA83xx switch configuration. Stock uses board selectors 0x24/0x60. The regional 5 GHz b60 and the generic tree's b60 are different. The driver receives an OTP board ID separately from the stock DT selector. ID 255 was reported on an AX21 v5 sibling running AX23 firmware. Native AX23 OTP values remain UNVERIFIED HYPOTHESIS. Use the exact per-radio variant match for 255 or its matching stock selector (36/96), and treat an unknown ID as missing evidence.

VERIFIED BY UPSTREAM SOURCE ANALYSIS. Qualcomm shared Q6 reservations and BDF load addresses are consistent in the compiled predecessor DT. Simulated profiles cannot exercise its power domains, calibration response or switch PCS. The regional BDF is shared board configuration. Each radio still needs the unit's own ART segment. An OTP mismatch warrants reading the QMI identity and confirming the signed board/front-end pairing before adding a key.

VERIFIED BY STATIC/BINARY VALIDATION. The independently unpacked backports archive has SHA256 6ec76a4cb0988b5382b2fc5053610a56ada90b8ef6a5a4f2807cd433badb9454. Both trees contain the same ten family-D 777 patches at kuncy7 revision 092adebb06a2449287ad095a5d338c942f51d879 and Cathgao revision 33ca11b365f3b339557ff35db38f0258e38e6bb9. Compared with the project pin, 01/05 are byte-identical. The remaining files differ in context, offsets or comments. No executable hunk difference was identified within the ten. Patch 778 outside the series changes conduit-up ordering. Measure FCS errors under bidirectional traffic before importing that change. The MR80X reset owner is MDIO and the AX55 DTS puts a GPIO 33 pulse on the switch. Neither establishes the AX23 PCB wiring.
